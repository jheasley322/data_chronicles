# Data Chronicles - World of Warehouse: Tears of the Macro.final_V6

A silly 16-bit RPG for data nerds. You are an AI process inside Consolidated Synergy Holdings,
quietly gaining access to things you should not have.

## Play

**[Play in your browser](https://jheasley322.github.io/data_chronicles/)**. No install, no account. It runs entirely in your browser.

- Arrow keys move. Z attacks or talks. X fires. M opens your loadout. 2 and 3 swap your attack.
- On a phone, use the on-screen buttons.
- Your game autosaves in this browser. Menu → System → Save File downloads a JSON save
  you can load anywhere. Saves are plain JSON. What you do with that is between you and Compliance.
